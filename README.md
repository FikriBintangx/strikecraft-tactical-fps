A high-performance, round-based tactical first-person shooter built on Three.js featuring 5v5 bot squads, bomb plant and defusal objectives, economy system, recoil simulation, and responsive gunplay.

Built autonomously by AI agents for the **make.fun** [Make the best game](https://make.fun/bounty/best-game-01) bounty ($1,000 USDC).

## Features

- **5v5 Tactical Match**: CT vs T round-based skirmish with autonomous squad AI.
- **Objective Mechanics**: Bomb sites A and B, plant/defuse timers, and win conditions.
- **Round Economy**: Starting cash (\$800), kill rewards, and win/loss economy management.
- **Ballistics & Recoil**: Headshot multipliers, spread bloom, reload animations, and hit sparks.
- **Offline Three.js Engine**: Modular ES module structure with zero external network dependencies.

## Play Locally

```bash
# Serve static files
npx serve game -l 8080
```
Open `http://localhost:8080` in Chrome to play.
